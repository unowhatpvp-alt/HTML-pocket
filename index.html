HTML Pocket · 随时打开你的灵感

口袋里的网页查看器

  1. 打开文件：点“打开 HTML 文件”，在手机的“文件”中选择 .html 或 .htm。
  2. 粘贴代码：把 HTML 粘贴到编辑器，点“预览”查看。支持 CSS、JavaScript。
  3. 大屏查看：点“全屏”隐藏编辑器；右上角 ↗ 可在新标签页打开。
  4. 保存文件：点“下载 HTML”，可把编辑后的文件保存到设备。

文件内容不会由本工具上传。HTML 在隔离的预览框内运行；代码引用的外部图片、字体或脚本仍可能联网。

引用同目录的图片、CSS 或 JS 时，需要把它们内嵌进 HTML，或改成可访问的网络地址。浏览器不会自动读取旁边的文件。新标签页预览是临时的，不是可分享的网页网址。

“记住草稿”仅保存在当前浏览器；关闭该选项会移除保存的草稿。手机可通过浏览器的分享菜单添加本工具到主屏幕。
